RS17G22 Datasheet Brief

Phase Tuner NewWorkload-aware automatic phase add/drop for RS17G22 rails

Replay a captured accelerator core-current trace against the rail, learn how big the next load step can be at each load level, and program a minimum active-phase floor per load level so that a step arriving while phases are shed stays inside the load-line window with probability at least 1 − α. Datasheet thresholds still set phase count for efficiency above the floor.

Rail under test

How the floor is set

  1. Score every step. Each rising edge in the calibration traces is simulated with 1 to 16 phases already on to find the fewest that keep VOUT inside the window.
  2. Calibrate per load band. The floor is a split-conformal upper quantile of those counts, so a new step in the band needs more with probability at most α.
  3. Replay held-out traces. The full add/drop logic (drop delay, hysteresis, undershoot reduction) runs on traces the floor never saw.
  4. Program it. One minimum-phase value per load band, written once to MTP next to the existing add/drop thresholds.

Features

High-Performance Multiphase Control

  • The RS17G22 is a Dual-rail PWMVID/AVSBus controller supporting up to 16 total phases (16+0 to 8+8)
  • Native Trans-Inductor Voltage Regulator (TLVR) support
  • Constant On-Time (COT) control for fast transient response
  • Automatic phase add/drop for improved light-load efficiency

Advanced Control & Optimization

  • Programmable DC load-line
  • Programmable overshoot and undershoot reduction
  • Field-programmable Multiple-Time Programmability (MTP)
